# AlesSystems

Software tools, practical applications, and engineering resources. Based in Denmark.

Our public projects span desktop utilities, web applications, and learning resources for software, hardware, and AI-assisted engineering.

## Selected projects

| Project | Overview |
| --- | --- |
| [JSON-to-PDF](https://github.com/AlesSystems/Json-to-PDF) | Offline desktop application for converting JSON objects and arrays into readable, searchable PDFs. |
| [ASCII Art Generator](https://github.com/AlesSystems/ASCII-art-generator) | Image and animated GIF conversion through a web app, command-line tool, and reusable TypeScript library. |
| [4ES-Dash](https://github.com/AlesSystems/4ES-Dash) | Personal Steam dashboard for exploring playtime, achievements, library value, and trends. |
| [Engineering Foundations](https://github.com/AlesSystems/engineering-foundations) | An evolving knowledge base covering software, hardware, production systems, and engineering with AI agents. |

## Contributing

Bug reports, documentation improvements, and focused pull requests are welcome.

- Read the repository's README and any contribution guidelines before making changes.
- For bugs, include reproduction steps, expected behavior, and relevant environment details.
- Discuss substantial changes in an issue before starting implementation.
- Keep pull requests focused and describe how the changes were verified.
